python3 tests/unit/tools/coverage_gate.py ratchet --summary S --baseline B [--toolchain T] [--previous-baseline P] [--markdown OUT.md] [--json OUT.json]
  status OK | RATCHET | FAIL; RATCHET prints the proposed baseline JSON (also written into the markdown with the line "Commit this as tests/unit/coverage-baseline.json")
python3 tests/unit/tools/coverage_gate.py propose --summary S --toolchain T --source "<text>"      prints a complete baseline JSON on stdout

python3 tests/unit/tools/coverage_gate.py diff --report D --threshold 80 [--exempt] [--markdown OUT.md] [--json OUT.json]   status PASS | NO_LINES | EXEMPT | FAIL
python3 tests/unit/tools/coverage_gate.py comment-target --comments C --marker '<!-- cn105-coverage-report -->'   prints one id or nothing

Input formats:
- gcovr --json-summary (S): top-level line_covered, line_total, branch_covered, branch_total, and files: [{filename (root-relative, e.g. components/cn105/cn105.cpp), line_covered, line_total, branch_covered, branch_total}]

- baseline (B, P): {"line": 38.12, "branch": 25.4, "line_covered": int, "line_total": int, "branch_covered": int, "branch_total": int, "toolchain": {...}, "source": "<text>"} or a provisional baseline {"line": 0.0, "branch": 0.0, "provisional": true, "toolchain": {...}, "source": "<text>"}
- diff-cover JSON (D), keys verified on diff-cover 10.6.0 output during research: report_name, diff_name, src_stats, total_num_lines, total_num_violations, total_percent_covered, num_changed_lines
- comments (C): a JSON array of GitHub issue-comment objects, or JSON Lines with one {"id": int, "body": str} object per line (gh api --paginate --jq output)
